IC-wD-MPNN
==========

**IC-wD-MPNN** is a motif-aware directed message-passing neural network for
polymer property prediction. It retains an atom-level graph representation
and augments message passing with explicit motif information at
polymerization interfaces.

Motifs provide a complementary semantic description of local chemical
structure. They are auxiliary representations, not nodes in a separate
hierarchical graph.
